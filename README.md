# War Thunder Market Calculator

A personal Gaijin Market flip calculator for checking market fee impact, profit, ROI, break-even sell price, target profit pricing, target ROI pricing, and simple flip risk.

This is only a calculator and analysis dashboard. It does not include bots, auto-buyers, auto-snipers, scrapers, or anything that interacts with the Gaijin Market.

## Run Locally

```powershell
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```powershell
npm run build
```

## GitHub Pages

The repository includes a GitHub Actions workflow that builds and deploys the app to GitHub Pages after pushes to `main`.

Expected Pages URL:
